# Setup pstack

Read [the client adapter](../../pstack/harnesses.md) before applying tool, model, transcript, or permission instructions. It overrides the Cursor-specific defaults below.

Follow [the setup steps](../../pstack/setup.md) for every harness, including Codex, Cursor, Claude Code, and OpenCode Go. Ask only for missing preferences. Resolve models through [the model policy](../../pstack/models.md).

Keep role labels in the setup steps as the shared contract. Keep exact model IDs, approved model series, access tiers, release preferences, and effort choices in personal harness settings. Do not introduce versioned model defaults in this skill.
